## 三、三条最有价值的方法论沉淀

1. **near-SAT 阶梯**（p003）：钉死已知 35 图 + 放开 k 条边与 k 条非边 + 第 36 顶点全自由 ⇒ 自由变量 630 → 2k+35 ⇒ 秒级判决；嵌套阶梯让一次 k=256 的 UNSAT 覆盖所有 k≤256。
2. **CP-SAT 的正确用法**（p009/p014）：不是裸求最优，而是「**给定紧上界的可行性** + 喂已知可行解当 hint」⇒ 裸模型 5.5 h 只到 2106，加 cap 后 UNKNOWN，加 hint 后才确认 incumbent 并给出下界。
3. **模 8 约束把目标值钉死**（p006）：E ≡ 2 或 6 (mod 8) ⇒ 搜索只需盯 574 一个值 ⇒ 省掉大量无效搜索。

## 四、踩过的坑（同一家族的 5 个 bug）

`--log` 只打 stdout ⇒ 产物从未落盘 / hint 的 KeyError 被 `except` 静默吞掉 / TA 的「回退」翻的是随机位 / hint 静默失败 /
**p011 的「改进」判据只查「能否排好全部输入」而漏查长度是否变短** ⇒ 69 万次「改进」其实把网络从 71 涨到 254。

⇒ **共同点：计数器在涨，但目标其实没达成。**
⇒ **教训：任何计数器都必须有一个独立复核层。** 五次全靠读日志才发现。
