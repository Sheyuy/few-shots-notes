# p004 · C7^⊠10 的独立集 — 方法与死路

工作目录：`/workspace/few-shots-work/p004-shannon-capacity-c7/`
板上纪录：134753（Itty, Rosin, Carstensen, Reichman 2026，arXiv:2607.21517）
方向：max，ε = 1（需要 ≥ 134754）

## 思路

### 1. 复现 Polak–Schrijver 的 367 点构造（可行）

arXiv:1808.07438 的构造是一条**参数化流水线**，我把每一步都独立实现并验证：

1. 取循环码 `S = { t·(1,q,q²,q³,q⁴) mod n : t ∈ Z_n }`（n=382, q=7 时 v=(1,7,49,343,109)）；
2. 每个词加上常数偏移 o=(40,123,40,123,40)；
3. 每个字母 i∈[0,n) 换成 `floor(i/(n/7))`，落到 Z_7^5；
4. 删掉所有与别的词相邻的词 → M（|M| = 327）；
5. 在"与 M 兼容"的子图 G 上求**最大独立集**并补进去 → |I| = 40。

结果 327 + 40 = **367**，与论文完全一致（|M|=327, |G|=71, α(G)=40 全部对上）。

第 5 步原来是用 Gurobi 算的；我自己写了一个精确求解器：分支定界 + **补图着色**上界（独立集在补图的每个色类里至多取一个，所以补图着色数是 α 的上界）+ 度 ≤1 顶点的强制归约。它把 α(G)=40 精确复现。

> 踩过的坑：最初把"G 本身的贪心着色数"当成 α 的上界——错的。G 的色类本身就是独立集，一个独立集可以在同一个色类里放很多点。必须用**团覆盖**（= 补图着色）做上界。

### 2. 为什么 368 点一旦拿到就赢

`367² = 134689 < 134753`。所以 α(C7^⊠5) 只要到 368，平方后就是 **135424** 点，
直接比板上纪录多 671 点，而且同时把 Θ(C7) 的下界抬到 368^(1/5) = 3.25964 > 3.25883262
（超过 Tandon 2026 的 500 维构造）。反过来，纪录 134753 < 368²=135424 也说明
**至今没人找到过 368 点的 C7^⊠5 独立集**。

### 3. 一个精确化观察

因为第 5 步的 G 覆盖整个 Z_7^5，所以
`max{ |M| + α(G(M)) : M ⊆ W 独立 }` 就是 α(C7^⊠5) 本身（W 是第 3 步的 n 个映射词）。
也就是说这条流水线加上"在 M 上做爬山"是一个**原则上精确**的 α(C7^⊠5) 求解器。

### D. 纪录集合本身是极大集

### 4. 构造的**合法性条件**（推导结果）
```
S = (B×B) ∪ {(u,x) : x∈T, u∈E(x)} ∪ {(x,u) : x∈T, u∈V(x)}
```
冲突只有三类：
1. 同族同 x：E(x)（或 V(x)）必须独立；
2. 跨族同 x：`(u,x)` 与 `(x,u')` 冲突 ⟺ u~x 且 x~u' ⟹ 需 `E(x)∩N(x)=∅` **或** `V(x)∩N(x)=∅`；
3. 跨族异 x：`(u,x)` 与 `(y,u')` 冲突 ⟺ u~y 且 x~u' ⟹ 若 u∈E(x) 且 u~y，则需 `V(y)∩N(x)=∅`
   （对称地，u∈V(x) 时需 `E(y)∩N(x)=∅`）。
另：重复点 `(u,x)=(x',u')` 当且仅当 x,x' 同时落在 T∩pool。
