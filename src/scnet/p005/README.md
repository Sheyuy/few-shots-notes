# p005 源码（2026-10-31 轮次）

F₃⁸ 中的帽集：目标 513（纪录 512）。这一轮没有找到 513，也没有证明 513 不存在。
下面每个数字都标了它的强度：**精确**（穷举/证明）、**有限范围**（给定输入）、
**未判定**（CP-SAT `UNKNOWN`/`FEASIBLE`，或启发式）。

关于乘积路线要注意：F₃⁶ 的 112 点帽集是**已知存在**的（α(F₃⁶)=112），
本地只搜到 85 说明那条子搜索太弱，不能据此排除乘积构造。这一条在报告里
只作为“未完成”，不作为负结论。

## 为什么不能写成“513 不存在”

- 所有 CP-SAT 结果都是 `UNKNOWN` 或 `FEASIBLE 512`，没有一个是 `INFEASIBLE`/`UNSAT`。
- r ≤ 13 的横截穷举只覆盖“删少量点再原地补回”的邻域；513 完全可能来自
  与基线无关的全新构造。
- 全局下界（α(F₃⁸) ≥ 513 是否可能）目前没有任何计算或证明支持。

因此 p005 的状态是：**512 仍是最好的可验证值，513 需要新数学构造。**
