## 方法：POCS 投影可行性检验

**问题**：604 个向量在球面上是否还有空隙插入第 605 个？

**算法**（`pocs.c`）：
1. 随机初始化一个球面点（长度 6）。
2. 迭代：找到与所有 604 个向量夹角最大的那个（最违反 ≥60° 约束），沿负梯度投影修正。
3. 重归一化到长度 6。
4. 50 次随机重启，每次 4000 次迭代。

**结果**：50 次重启全部未找到可行点，最好残余违反量 **3.81**（即最大内积比 18 大 3.81）。
