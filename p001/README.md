## 方法：POCS 投影可行性检验

**问题**：604 个向量在球面上是否还有空隙插入第 605 个？

**算法**（`pocs.c`）：
1. 随机初始化一个球面点（长度 6）。
2. 迭代：找到与所有 604 个向量夹角最大的那个（最违反 ≥60° 约束），沿负梯度投影修正。
3. 重归一化到长度 6。
4. 50 次随机重启，每次 4000 次迭代。

**结果**：50 次重启全部未找到可行点，最好残余违反量 **3.81**（即最大内积比 18 大 3.81）。

## 结论

604 向量配置在局部投影意义下**已满**，没有可插入第 605 个向量的空隙。要突破需要全新的构造，而非局部微调。

- **纯形态枚举**：5 类 norm²=36 族共约 46 万候选，全部被现有向量挡住。
- **覆盖半径量化**：100 万随机方向 + 150 起点子梯度，最小 `max cos = 0.57765`（54.71°），再加 60 起点 0.5794，均远高于 60° 阈值 0.5——任意方向（不只格点）都会被挡住。
- **换 norm²=72 完整排查**：把 604 乘 √2 后，在 norm²=72 点阵找第 605 个向量。
  - 修正了一个 DP 采样 bug（`s+w` 与 `s−w` 不一致，导致生成的“随机”向量几乎全是单坐标向量）。
  - 一般采样 10 万个：86 个内积可行，但范数 `(72, b≠0)` 与骨架 `(72, 0)` 不同，全部非法。
  - 纯形式 `Σpq=0` 采样 20 万个：合法向量 0 个。
- 给后来者：**范数必须逐分量相同**，只查 `Σ(p²+2q²)` 会得到假阳性；要突破必须从零构造另一套 604。
