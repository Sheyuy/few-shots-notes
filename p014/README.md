## 结论

- 没有证据表明 622 不存在；证据表明**通用退火弱了一到两个数量级**：
  在一个确实有解的场景（L=623）都到不了 0。
- 三种独立方法（退火、CP-SAT、±1 tabu）在同一实例上全部失败，说明 622 至少
  在 623 的邻域里不存在，且简单局部搜索够不着。
- 题面还写明：复审者已扫过 Singer/Bose 构造 q=29,31,32 的**所有单位与所有窗口**，
  没有比 623 更短的。这与 Rokicki–Dogon 的"假设 A"（n>16 时构造即最优）一致。
- 要真打，只剩精确 DFS（差分位图剪枝，OGR 那种）——那是数年级别的算力，25 小时不够。
