- 基线 623 来自 Singer 构造（射影平面 q=29，模 871 的 30 元完全差集截取），
  题面自己写明这是"构造给出的最好值"，不是已证最优。

## 探针（本仓库 `src/scnet/p014/golomb.c`）

定长 L 上的模拟退火，代价 = 重复差分对数，代价 0 即合法。

| 试验 | 起点代价 | 结果 |
|---|---|---|
| L=623 用基线种子 | 0 | 立刻 0（自检通过） |
| L=622 用基线压缩种子 | 14 | T=0.2…3.0 共 2×10⁷ 步，**从未低于 14** |
| L=623 随机起点 | 133 | 60 s 降到 31 |
| L=622 随机起点 | 178 | 30 s 降到 30 |

## 结论

- 没有证据表明 622 不存在；证据表明**通用退火弱了一到两个数量级**：
  在一个确实有解的场景（L=623）都到不了 0。
- 要真打这题，需要专用求解器（差分三角 tabu + ±1 移动 + 平台处理，
  或带传播的 CP/SAT 模型），不是现有工具。
