## 攻关方法概览

- **精确 SAT 编码**（p003）：全量 630 边变量、2,006,697 子句；带自同构商图压缩到 108–326 变量；CaDiCaL、Kissat、Minisat22 多求解器并行。
- **局部搜索 + 验证器复核**（p003/p005/p006）：C 语言实现模拟退火/禁忌搜索，每次候选都经官方 verifier 复核；发现并修复过一次假阳性（增量计数 bug）。
- **位图完整枚举**（p004）：7^5×7^5 分组 + 64-bit 位图，0.6 秒判定极大性；1↔2/2↔3/3↔4 交换精确搜索。
- **投影可行性检验**（p001）：POCS 在 604 向量约束下随机初始化 + 投影迭代，找可插入的第 605 个向量。
- **球冠覆盖量化**（p001，CodeArts）：100 万随机方向 + 210 个多起点子梯度，最小 `max cos = 0.5776`（54.7°），远高于 60° 阈值 0.5；并完整排查 norm²=72 点阵。
- **全局 CP-SAT**（p005，CodeArts）：6561 变量、7,173,360 条线约束、512 hint；构建约 183 秒，64 worker 稳定在约 137 GB；256 worker 必 OOM。
- **分层精确最大团**（p005，CodeArts）：固定两层，第三层候选集上求精确最大团（192/160/160），证明单层坐标下降封死。
- **射影截面与精确冲突壳层**（p005，Kimi）：复核 2744/6464/13312 点射影帽；六个 496 点种子的 704 点池全部 `OPTIMAL 496`，原基线第 4–12 壳层全部 `OPTIMAL 512`；第 13 壳层仍未判定。
- **真值表去重**（p008）：256-bit 真值表比对 102 门 AES 电路，查重复/死/常量门。
