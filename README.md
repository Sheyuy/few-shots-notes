- **精确 SAT 编码**（p003）：全量 630 边变量、2,006,697 子句；带自同构商图压缩到 108–326 变量；CaDiCaL、Kissat、Minisat22 多求解器并行。

- **真值表去重**（p008）：256-bit 真值表比对 102 门 AES 电路，查重复/死/常量门。
