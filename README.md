## 攻关方法概览

- **精确 SAT 编码**（p003）：全量 630 边变量、2,006,697 子句；带自同构商图压缩到 108–326 变量；CaDiCaL、Kissat、Minisat22 多求解器并行。
- **局部搜索 + 验证器复核**（p003/p005/p006）：C 语言实现模拟退火/禁忌搜索，每次候选都经官方 verifier 复核；发现并修复过一次假阳性（增量计数 bug）。
- **位图完整枚举**（p004）：7^5×7^5 分组 + 64-bit 位图，0.6 秒判定极大性；1↔2/2↔3/3↔4 交换精确搜索。
- **审计后的连通超图枚举**（p004，SCNet）：C++17 重写交换排除，显式 5 字段键、动态容器、`complete/UNKNOWN/INCOMPLETE` 三态；k≤5 在论文集与重排集上 `found=0`；k=6 的五个阶段族（自然 300 万、rank-5 4,199 万、rank-4 6.44 亿、rank-3 17.5 亿、连通对 3,759 万，合计约 24.8 亿实例）也全部 `found=0`，但这些族合起来仍不等于所有 6-集。
- **精确 2-SAT + 权重化删点 CP-SAT**（p004，SCNet）：九对族 50 个候选全部 UNSAT；六个固定模型的最小删点被证明为 17/18/32，17 恰比门槛多 1。
- **分片式深层交换与邻域完备性**（p004，SCNet）：`sixm3 --deep6 --shard i/64` 把 rank-4 层 6.44 亿实例跑完（`found=0`）；`d9_scan.py` 对 `|D|=9` 的 1,450 个构造全部判非独立；`xk.c` 在 C7⁵ 上把“删 k 加 k+1”做到 `k=8` 完备（12.7 亿节点、16.8 小时），R367 的 8 点邻域内没有 368 点集。
- **投影可行性检验**（p001）：POCS 在 604 向量约束下随机初始化 + 投影迭代，找可插入的第 605 个向量。
- **球冠覆盖量化**（p001，CodeArts）：100 万随机方向 + 210 个多起点子梯度，最小 `max cos = 0.5776`（54.7°），远高于 60° 阈值 0.5；并完整排查 norm²=72 点阵。
- **全局 CP-SAT**（p005，CodeArts）：6561 变量、7,173,360 条线约束、512 hint；构建约 183 秒，64 worker 稳定在约 137 GB；256 worker 必 OOM。
- **分层精确最大团**（p005，CodeArts）：固定两层，第三层候选集上求精确最大团（192/160/160），证明单层坐标下降封死。
- **射影截面与精确冲突壳层**（p005，Kimi）：复核 2744/6464/13312 点射影帽；六个 496 点种子的 704 点池全部 `OPTIMAL 496`，原基线第 4–12 壳层全部 `OPTIMAL 512`；第 13 壳层仍未判定。
- **连通集枚举 + 增量计数器**（p004，SCNet）：`xk7/xk8/xk9/xk10` 四个实现枚举同一批对象（连通 k+1 集且 `|T(A)| ≤ k`），四组随机自测与暴力逐例一致；k=9 单线程从 1,268 s 压到 204 s；k=12 两个实现各证 `count=0`。节点数每 k 增长 6.80×，据此判定 k=13 需 ≈39 h。
- **定长退火 / CP-SAT / ±1 tabu**（p014）：三种独立方法攻 29 阶 Golomb 尺的 L=622，全部停在热启动的 14 个重复差分上；CP-SAT 不给提示时连已知存在的 623 都找不到。
- **真值表去重**（p008）：256-bit 真值表比对 102 门 AES 电路，查重复/死/常量门。
