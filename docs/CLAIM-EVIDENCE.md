# 结论 → 证据对照表

这张表把 README 和报告里出现的每个数字，指到能重跑出它的脚本、数据或日志。
**强度**沿用报告的四档：精确 / 有限范围 / 未判定 / 已作废。
**状态**一栏说明证据是否在本仓库里：

- `归档`：脚本或数据在仓库中，按 `REPRODUCE.md` 的命令可离线复算；
- `代码归档，日志缺失`：程序在，但当时那次运行没有留下 stdout；
- `未归档`：一次性内联脚本或远端运行，仓库里没有对应文件——这类条目只能当线索，
  不能当可复现的证据。
