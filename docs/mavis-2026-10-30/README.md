python3 harvest_dim5.py R_paper.txt my-id

#      VERIFIER: {"valid":true,"score":"134689",...}

### p003：SAT 解 → (4,6)-Ramsey 图

```bash
# 1) 生成对称类的 CNF（自带群公理自检）
python3 sym_sat.py zdihGm9c2 0
# 2) 求解（CryptoMiniSat / minisat 均可）
cryptominisat --verb 1 cnf/zdihGm9c2.cnf > out.log
# 3) 提取并独立校验
grep "^v " out.log > out.sat && python3 extract.py out
# 4) 官方验证器 + 建 shot
python3 p003_harvest.py shot out_graph.json r46-36
```

**这条链路的正确性已被证明**：用 N=8 的已知答案案例（C₈ 本身是合法的 (4,6)-图 ✅）
跑完整条链路，得到 `VALID CERTIFICATE` ✅✅ —— 所以**任何 SATISFIABLE 的解必然是合法的
36 顶点图 ✅**，不会给出假阳性 ✅。
